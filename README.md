# Ecommerce – AI catalog + login + live support agent

## Πρώτη φορά
1. `npm run setup`
2. `cp server/.env.example server/.env` και συμπλήρωσε: GEMINI_API_KEY, JWT_SECRET, ADMIN_EMAIL
   (JWT_SECRET: node -e "console.log(require('crypto').randomBytes(48).toString('hex'))")
3. `npm start`  → server :5000 + site :5173

## Σημαντικό για το login
Οι λογαριασμοί ζουν στο `server/data/app.db` του φακέλου που τρέχεις. Αν τρέξεις τον server από
άλλον φάκελο, ο λογαριασμός δεν υπάρχει εκεί και το login αποτυγχάνει. Κάνε νέα εγγραφή ή αντίγραψε
τον φάκελο `data/`. Ο λόγος αποτυχίας γράφεται πάντα στο τερματικό του server (`[auth] login failed ...`).
Πρέπει να τρέχει ΜΟΝΟ ένας server στο :5000.

## Πώς μαθαίνει ο AI
- Μετά από κάθε ανέβασμα ελέγχει τη φωτογραφία και, αν έχασε κάτι, δοκιμάζει μια προσωπική οδηγία.
  Ενεργοποιείται μόνο αν βρει περισσότερα αντικείμενα στην ίδια φωτογραφία.
- Από το chat ή το κουμπί «Λάθος ανίχνευση;» σε κάθε κάρτα λες π.χ. «δεν βλέπει τις μπότες μου».
- Οι οδηγίες είναι προσωπικές. Ο admin μπορεί να τις κάνει κοινές (Κανόνες AI → «Κοινή για όλους»).
- Κάθε οδηγία απενεργοποιείται με ένα κλικ (💬 → «Οι οδηγίες μου»).
